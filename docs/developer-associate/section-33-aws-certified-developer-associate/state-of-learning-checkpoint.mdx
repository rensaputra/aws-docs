## 🎯 4 Essential Exam Rules to Keep in Mind

1. **Answer Every Single Question:** There is **no negative marking** on the AWS exam! If you run into a tough scenario, use process of elimination to narrow down distractors, make an educated guess, flag it, and keep moving.
2. **Unscored Experimental Items:** Remember that 15 out of the 65 questions are unscored experimental questions being tested by AWS for future exam iterations. Treat every question with focus, but don't let one unusually bizarre or fringe question throw off your momentum!
3. **Pacing Engine:** You have **130 minutes for 65 questions** (~2 minutes per question). Save the long, multi-select scenarios for the second pass if you get stuck.
4. **Target Score:** You need a scaled score of **720 / 1000** to earn the certification.

You have done the hard work, written the code, built the IaC templates, and cleaned up your account. Now it's time to run the practice exam and prove you're an AWS Certified Developer! 🚀
